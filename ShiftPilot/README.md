# ShiftPilot

A small web app for managing staff. This is the first version of my Cloud Application Development project.

## What works so far
- See a list of employees
- Add an employee with a name and role

The data is only stored in the page for now. Refreshing resets the list.

## Run the project
1. Install Node.js if needed.
2. Open this folder in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open the local address shown in the terminal.
